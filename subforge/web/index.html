Connect a remote worker

Set CONVERTER_COORDINATOR_URL on the remote machine, configure the same dedicated CONVERTER_WORKER_TOKEN on the coordinator and worker, and map shared media with CONVERTER_WORKER_MAPPINGS. Both machines must see the same media and staging directories. Start subforge-worker from the CPU or CUDA image. Keep the dashboard password separate from worker credentials.
