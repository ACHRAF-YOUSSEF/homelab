Connect a remote worker

Remote workers use a dedicated worker token and explicitly mapped shared media folders. On the other machine, set the coordinator origin in CONVERTER_COORDINATOR_URL, configure the dedicated CONVERTER_WORKER_TOKEN, and map shared media with CONVERTER_WORKER_MAPPINGS. Start subforge-worker from the CPU or CUDA image. Both machines must see the same media and staging directories. Keep the dashboard password separate from worker credentials.
